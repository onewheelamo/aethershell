Besoin : Îlot central (Barre de statut).
- Affichage permanent : Heure et Date.
- Interaction Survol (Hover) :
  - Affichage d'un panneau éphémère.
  - Contenu : Heure, Date, Emplacement géographique et Météo locale succincte.
- Interaction Clic (Heure) :
  - Affichage d'un calendrier du mois en cours.
  - Navigation : Flèches pour changer de mois (précédent/suivant).
  - Intégration Nextcloud : Point de couleur sur les jours ayant un événement.
  - Détails : Clic sur un jour -> extension du panneau avec la liste des événements du jour via Nextcloud.
- Configuration (Icône roue crantée) :
  - Action : Ouvre un panneau de configuration général du système.
  - Options configurables : 
    - Système : Heure, réseaux, résolutions d'écran.
    - Esthétique : Fond d'écran, jeux de couleurs, aspect du bureau (gaps, couleurs spécifiques).
    - Contrôles : Raccourcis clavier.
